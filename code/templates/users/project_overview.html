🔋 EV Battery SOH Forecasting

📌 Project Overview

This system enhances the lifespan and efficiency of electric vehicle (EV) batteries by predicting their State of Health (SOH) using advanced machine learning models. Users can input battery metrics and instantly receive insights on battery performance and health.

Key Features: Predict SOH, visualize results, assess battery health, and estimate time-to-replacement.

💡 Why This Matters

  • Performance Monitoring: Keep your EV battery in optimal condition.
  • Preventive Maintenance: Identify issues early to avoid failure.
  • Cost Efficiency: Avoid unnecessary replacements and repairs.
  • Eco-Friendly: Supports sustainable electric vehicle usage.

🧠 Algorithms Implemented

  • XGBoost Regressor: High-accuracy SOH forecasting.
  • LightGBM Regressor: Fast and efficient for real-time predictions.
  • Random Forest Regressor: Reliable baseline and interpretability.

📦 Libraries & Technologies

  • Data Handling: pandas, numpy
  • ML & Modeling: xgboost, lightgbm, scikit-learn, joblib
  • Visualization: matplotlib, seaborn, plotly
  • Web Framework: Django

🌐 Application Features

  • Training Module: Trains models and visualizes:
    • Correlation Heatmap
    • Actual vs Predicted Charts
    • Evaluation Metrics (MAE, MSE, RMSE, R²)
    • Feature Importance
  • SOH Prediction Interface: Accepts input & displays:
    • Predicted SOH
    • Health Status
    • Replacement Estimation
    • Performance Tips
